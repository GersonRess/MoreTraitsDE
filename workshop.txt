title=More Traits Definitive Edition
description=[h1]More Traits Definitive Edition[/h1]
description=
description=[b]A standalone community continuation of More Traits (ToadTraits) for Project Zomboid Build 42.20.[/b]
description=
description=The goal of this project is to preserve the original More Traits experience as closely as possible while bringing it forward to the current supported version of Project Zomboid.
description=
description=[hr][/hr]
description=
description=[h2]What This Mod Does[/h2]
description=
description=[list]
description=[*]Brings More Traits forward to Project Zomboid Build 42.20.
description=[*]Preserves the original traits, trait costs and intended behavior as closely as possible.
description=[*]Fixes traits and functionality that were no longer working correctly.
description=[*]Completes missing strings in languages already supported by the original mod.
description=[*]Performs a large-scale refactor following the DRY (Don't Repeat Yourself) principle, introducing shared helpers, unifying duplicated functionality and reorganizing the original codebase to make it easier to maintain, debug and expand in the long term.
description=[*]Is compatible with Multiplayer.
description=[*]Supports replacing the original More Traits during an existing playthrough.
description=[/list]
description=
description=[b]This is not a rebalance.[/b]
description=
description=The purpose of this continuation is not to redesign More Traits, but to keep its original experience intact while making it work properly on the current game version.
description=
description=[hr][/hr]
description=
description=[h2]What This Mod Does Not Do[/h2]
description=
description=[b]Dynamic Submod is not included.[/b]
description=
description=The Dynamic submod from the original More Traits project was not worked on as part of this continuation.
description=
description=Bringing More Traits forward, refactoring the original codebase, fixing broken functionality and dealing with compatibility was already a very large project on its own. The Dynamic Traits submod was therefore left outside the scope of this work.
description=
description=
description=[b]It should not throw red errors all over the place.[/b]
description=
description=Based on my testing and the corrections made during development, the mod does not produce red errors during normal use. That said, I cannot test every possible trait, interaction, mod combination or game scenario (SP/MP/COOP), and I can still make mistakes. Feedback and bug reports are therefore greatly appreciated.
description=
description=[hr][/hr]
description=

description=
description=[h2]Compatibility & Testing[/h2]
description=
description=[b]Build 42.20 STABLE[/b]
description=
description=[b]Multiplayer compatible.[/b]
description=
description=The refactor was performed with Multiplayer compatibility in mind, but not every trait, interaction, mod combination, or SP/MP/Co-op scenario has been exhaustively tested.
description=
description=[b]Mid-save replacement is supported.[/b]
description=
description=Replacing the original More Traits with this fork during an existing playthrough is safe and should not cause problems with existing saves.
description=
description=[b]Not retrocompatible.[/b]
description=
description=This project is focused on the latest supported base-game version and will continue to follow future game updates rather than maintaining compatibility with older versions.
description=
